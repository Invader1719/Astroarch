# 🌌 Сайт с задачами по олимпиадной астрономии

## 🎯 Цель проекта

Создать **публичный сайт-агрегатор** задач по олимпиадной астрономии (и другим наукам в будущем), начиная с задач ВсОШ, СПбАО, МАО и др.

Функционал включает:

- расширенную фильтрацию задач;
- авторизацию и роли пользователей;
- личный кабинет;
- внутреннюю валюту **люмина** за вклад.

> **Основатель проекта:** Станислав Потапов

---

## 🏗️ Архитектура

| Компонент    | Стек технологий |
|--------------|------------------|
| **Фронтенд** | React, TypeScript, TailwindCSS, ShadCN UI, React Router, Vite |
| **Бэкенд**   | FastAPI, SQLAlchemy, PostgreSQL |
| **Аутентификация** | JWT (хранение токена в localStorage) |
| **Разработка** | PyCharm, VSCode, DataGrip |
| **DevTools** | Swagger UI, React DevTools, pgAdmin |
| **Запуск**   | localhost:5173 (frontend), localhost:8001 (backend) |

---

## 🔐 Роли пользователей

| Роль       | Права |
|------------|-------|
| `guest`    | Только просмотр задач |
| `user`     | Базовый функционал |
| `moderator` | Добавление задач, доступ к личным кабинетам |
| `admin`    | Модерация и редактирование |
| `founder`  | Полный контроль (все права) |

---

## 🧩 Функциональность

- Просмотр задач
- Фильтрация по источнику, теме, подтеме, году, классу
- Регистрация и вход (JWT)
- Система ролей
- Личный кабинет (ФИО, ник, роль, люмины)
- Начисление люмин:
  - `+3` — за условие
  - `+5` — за решение
  - `+2` — за ответ
- Добавление задач (по ролям)
- Swagger UI: http://localhost:8001/docs

## 🧠 Структура проекта

### Frontend (`frontend/src`)

```
context/
└── AuthContext.tsx      ← логика токенов

pages/
├── TasksPage.tsx        ← список задач
├── LoginPage.tsx        ← форма входа
├── RegisterPage.tsx     ← регистрация
├── AddTaskPage.tsx      ← добавление задач
├── ProfilePage.tsx      ← личный кабинет

App.tsx                  ← роутинг
main.tsx                 ← точка входа
index.css                ← Tailwind стили
```

### Backend (`backend/app`)

```
main.py                  ← точка входа FastAPI
core/database.py         ← подключение PostgreSQL

models/                  ← SQLAlchemy модели
schemas/                 ← Pydantic схемы
crud/                    ← CRUD операции
api/                     ← Роутеры (auth, task, source, topic и др.)
dependencies/auth.py     ← проверка токенов и ролей
```

---

## 🗃️ База данных

- `users` — имя, ник, пароль (хэш), роль, люмины
- `tasks` — условие, ответ, решение, источник, сложность
- `sources`, `topics`, `subtopics` — фильтры
- `task_topic`, `task_subtopic` — связи многие-ко-многим

---

## 🌐 API

```
POST /auth/register      — регистрация
POST /auth/login         — логин
GET  /tasks/             — получить задачи + фильтрация
POST /tasks/             — добавить задачу (по ролям)
GET  /sources, /topics, /subtopics — фильтры
```
